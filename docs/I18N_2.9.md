## Languages and header

The globe selector in the header offers **Italiano**, **English** and **简体中文** (Simplified Chinese). Language selection takes effect immediately and is retained after restart. Italian remains the default. The selector and Open/Save/Export actions share a 36 px height and vertical alignment; the language label remains available to assistive technology.

中文：点击顶部地球图标旁的语言菜单，选择 **简体中文**。语言设置会自动保存；项目名称和自定义内容保持原样。

| Interface | Preference code | Qt locale |
| --- | --- | --- |
| Italian, default | `it` | `it_IT` |
| English | `en` | `en_US` |
| Simplified Chinese | `zh` | `zh_CN` |

`zh-CN` and `zh_Hans_CN` preferences normalize to `zh`. Traditional Chinese is not a separate catalog. Preferences reside in `settings.json`; unrelated settings are preserved. See [persistent paths](INSTALLATION.md#persistent-files-and-paths).

## Catalogs and rendering

- `locales/it.json`, `en.json`, `zh.json`: 1,204 shared message IDs, used by static `data-i18n` elements and dynamic frontend controls.
- `translations/s5studio_{it,en,zh}.ts` and `.qm`: 291 active Qt messages per language. Native UI uses `self.tr()`; translators are retained for the application lifetime.
- `translations/qtbase_zh_CN.qm`: Qt translations for standard Chinese dialog actions; application messages use the Studio catalog.
- Offline JSON loads through QtWebChannel for the file origin, with fetch available for HTTP. Missing messages fall back to Italian.
- Chinese uses installed fonts in this order: Microsoft YaHei UI, Microsoft YaHei, Noto Sans CJK SC, PingFang SC, then sans-serif. No CJK font is redistributed. Glyph coverage depends on the system's installed fonts.

**Why:** offline catalogs make language selection independent of network access. Stable message IDs and unchanged selector values preserve project compatibility. The interface language does not rewrite project names, custom layer names, user artwork, watchface calendar labels or sensor bindings.

## Translation workflow

```powershell
python -X utf8 scripts/update_translations.py --compile
python -X utf8 -m pytest tests/test_i18n.py tests/test_bundle_contents.py tests/test_file_dialogs.py tests/test_color_picker.py -q -m "not integration"
python -X utf8 scripts/check_editor_2_9.py
python -X utf8 scripts/check_localization_2_9.py --language zh
```

The automation extracts frontend messages and Qt source strings, updates all three TS catalogs and compiles QM files. Preserve placeholders such as `{v0}` and `%1`, stable IDs and source contexts. Completed context-specific Qt translations are retained. Packaging repeats catalog generation and personal hand-set synchronization. ## Validation and scope

Version 2.9 passed **59 targeted source tests**, **16 source-editor checks** and **161 rendered Chinese UI contexts**. Header geometry was checked at 1120 and 1440 px in all three languages, and the Chinese rendering was inspected visually. The executable is verified statically against source and resource hashes; it was not launched or tested in an isolated environment.

The seven watch Lua modules are unchanged from 2.8. No new device test, demonstration watchface ZIP or regression backup was performed. The last recorded device/firmware confirmation remains separate from these desktop checks.

The catalog now includes the synchronized **Swatch Luce** set: 12 personal sets, 632 effective hand models and 90 discs. **Bulova remains the only bundled project example.** Existing projects can still be opened; other personal projects, preferences and recovery data are excluded.
